# Apollinaria Vorobyeva — Portfolio

Персональный сайт-портфолио графического и моушн-дизайнера.

## Стек

- HTML5
- CSS3 (модульно: base / layout / effects)
- Vanilla JS (ES-модули)
- Canvas API

## Возможности

- Неоновая анимированная сетка + частицы (canvas)
- Кастомный курсор с magnetic-эффектом
- Typewriter, глитч-эффекты, reveal-анимации
- Мультиязычность (RU / EN)
- Переключение цветовых палитр
- Адаптивная вёрстка

## Структура

- `index.html` — разметка
- `css/base.css` — переменные, ресет
- `css/layout.css` — структура секций
- `css/effects.css` — неон, глитч, анимации
- `js/main.js` — точка входа
- `js/i18n.js` — переводы
- `js/ui.js` — интерфейс
- `js/animations.js` — анимации
- `js/canvas-bg.js` — фоновая сетка + частицы
- `js/cursor.js` — кастомный курсор
